How it works
  1. 1. Get prices

    Financial Datasets returns the stock price and daily change.

  2. 2. Find sources

    Exa searches the last 72 hours and returns links and quoted passages.

  3. 3. Classify passages

    Jev labels each source's relevance and whether it reports a concrete development.

  4. 4. Build the draft

    The app sorts sources using those labels and dates. You review uncertain sources.
